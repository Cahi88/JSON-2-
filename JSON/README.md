# EKEB — Журнал проверок

## Описание
Программа для ведения журнала проверок сайта EKEB.

## Возможности
- Просмотр и добавление проверок.
- Изменение статусов.
- Просмотр статистики.
- Сохранение данных в JSON.

## Файлы проекта
- `main.py` — главное меню.
- `cases.py` — логика проверок.
- `storage.py` — работа с файлами.
- `cases.json` — хранение данных.

## Запуск
```bash
python main.py
```

## Статусы
- `pending` — ожидает проверки.
- `pass` — успешно.
- `fail` — ошибка.

## Технологии
Python, JSON.
